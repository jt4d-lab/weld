# Слои модулей

Модуль публикует свой API точками входа. Точек входа у модуля может быть одна или несколько.

## Модуль с одной точкой входа

Модуль с одной точкой входа публикует API через корневой баррель:

```
/modules/auth/index.ts
```

Больше наружу из модуля ничего не выходит: всё остальное — его внутреннее дело.

## Модуль с несколькими точками входа

Модуль с несколькими точками входа публикует все точки входа, расположенные непосредственно в его
корневой директории, если они не помечены приватными соглашениями:

```text
/modules/auth/entities
/modules/auth/widgets
```

Точка входа относится к слою, если её имя совпадает с именем из `moduleLayers` после исключения
префикса приватности. Например, при настройке:

```js
moduleLayers: ['entities', 'widgets'];
```

`/modules/auth/entities` относится к слою `entities`, а `/modules/auth/widgets` — к слою `widgets`.

Слои сохраняют порядок из `moduleLayers`: `widgets` может импортировать `entities`, а `entities` не
может импортировать `widgets`.

## Приватность точек входа

Слой с префиксом приватности в `moduleLayers` недоступен из вышестоящих модулей. Префикс в настройке
делает слой приватным, но не требует такого же префикса у его директории.

```js
moduleLayers: ['_entities', 'widgets'];
```

```text
/modules/auth/entities
/modules/auth/widgets
```

В этом случае `entities` — приватная точка входа, хотя её директория не начинается с `_`.
Вышестоящий модуль не может импортировать `/modules/auth/entities`.

Точка входа с префиксом приватности в имени директории также недоступна из вышестоящих модулей, даже
если соответствующий слой в `moduleLayers` указан без префикса.

```js
moduleLayers: ['entities', 'widgets'];
```

```text
/modules/auth/_entities
/modules/auth/widgets
```

Здесь `_entities` остаётся приватной точкой входа, несмотря на отсутствие префикса у `entities` в
`moduleLayers`. Поэтому приватность слоя задаётся любым из двух условий: префиксом в `moduleLayers`
или префиксом директории.

## Кастомные точки входа

Точки входа, чьи имена отсутствуют в `moduleLayers`, называются кастомными. Они относятся к
`@custom` — синтетической метке, которая в конфиге не пишется. Например, при настройке:

```js
moduleLayers: ['entities', 'widgets'];
```

кастомными будут `/modules/auth/interceptors` и `/modules/auth/providers`:

```text
/modules/auth/interceptors
/modules/auth/entities
/modules/auth/widgets
/modules/auth/providers
```

Модуль с одной точкой входа тоже попадает в `@custom`: его точка входа — корневой баррель, а не слой
из `moduleLayers`.

Для других модулей точки входа обрабатываются в следующем порядке:

```text
@custom, entities, widgets
```

Внутри собственного модуля используется порядок:

```text
@custom, entities, widgets, @custom
```
