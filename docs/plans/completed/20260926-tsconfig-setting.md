# План: настройка имени tsconfig

## Цель

Добавить общую настройку `tsconfig`, которая задаёт имя файла, передаваемое вторым аргументом
`getTsconfig`. Настройка должна работать как в `settings.weld`, так и как переопределение в опциях
конкретного правила.

## Согласованные решения

- Имя настройки: `tsconfig`.
- Тип значения: строка.
- Приоритет источников:
    1. `options.tsconfig`;
    2. `settings.weld.tsconfig`;
    3. `'tsconfig.json'`.
- Настройка влияет только на автоматический поиск алиасов из tsconfig.
- Явные `options.aliases` или `settings.weld.aliases` по-прежнему полностью отключают автопоиск.
- Значение передаётся без нормализации непосредственно вторым аргументом `getTsconfig`.
- Отдельное чтение `settings.weld` в `resolveHostAndAliases` не добавляется: формат настроек
  остаётся инкапсулированным в `src/settings/`.
- Геттер настройки называется `getTsconfigName`, чтобы не путать его с библиотечной функцией
  `getTsconfig`.
- При отсутствии настройки сохраняется текущее поведение с `'tsconfig.json'`.
- Кэш загрузчика учитывает и директорию поиска, и имя tsconfig.
